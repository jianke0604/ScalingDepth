Contribute

Add a method in 3 steps

Fork the repo

Fork keyu-wang-2002/ScalingDepth on GitHub.

Edit one file

Append an entry to SD.methods (or SD.papers) in assets/js/data.js. Formulas use KaTeX syntax.

Open a pull request

Preview locally with python3 -m http.server. Once your PR is merged, the site updates on GitHub Pages.
